TabCrew

Works with your AI coding agents.

Any MCP client can connect to the free local TabCrew daemon: OpenCode, Claude Code and more.

  • One command to install: npx tabcrew setup
  • Step-by-step control with observe / act
  • Hand over whole goals with browse
  • Open source (MIT)
